# Терміни · модуль 01

| Термін | Що це |
|---|---|
| **Invoice** | Намір зібрати/виплатити суму; ще не факт |
| **TAKE** | Заявка записана (`created`) |
| **FILL** | Факт rail (`captured`) |
| **Pending** | Чекаємо зовнішній крок |
| **Idempotency-Key** | Повтор create не плодить другий invoice |
| **Webhook** | Підписане повідомлення мерчанту про зміну статусу |
| **Broker** | Черга між API і webhook worker (у нас RabbitMQ) |
